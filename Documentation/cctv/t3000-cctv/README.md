# T3000 CCTV user manual

This folder is the **T3000 CCTV product book** for homeowners and building operators.

Sibling folders under `Documentation/cctv/` (`unifi-protect/`, `reolink/`, `synology-surveillance-station/`) are **vendor inspiration only**. They are not Temco documentation and they do not describe what T3000 ships.

| Start here | What it is |
| --- | --- |
| **[T3000_CCTV_User_Manual.md](T3000_CCTV_User_Manual.md)** | Operator manual: Tools → CCTV, first run, ONVIF/RTSP, live view, and what is coming next |
| [images/](images/) | Figure placeholders `01`–`09`. Real screenshots belong in the pull-request conversation |

T3000 CCTV still uses localhost **go2rtc** (required for live video) and optional **MediaMTX**. This folder does not change that.

Installer / developer notes stay in [DEMO.md](../../../DEMO.md) and [nvr.md](../../nvr.md).

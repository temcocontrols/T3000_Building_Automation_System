# UniFi Protect Recording Modes & Schedules

UniFi Protect offers flexible recording modes and schedules to ensure longer retention of key footage in compliance with HIPAA or PCI requirements. 
## Recording Modes 

Choose from the following modes: 
- Always – Continuous recording for complete coverage. 
- Detection Only – Records only triggered events to reduce storage and incidental footage. 
- Never – Disables recording for specific cameras. 
An effective strategy for meeting HIPAA or PCI retention requirements is to use Detection Only recording in regions of low activity. This allows you to maintain footage of key events without using excessive storage for inactive recordings. Access this in Devices > [Select Camera] > Recording Mode . 
## Recording Retention 

Set retention periods to manage storage and meet regulatory needs, ensuring essential footage is stored only as long as necessary. Auto retention manages storage limits, while custom settings retain footage longer for audits or investigations. HIPAA and PCI regulations often require storage only for specific areas and periods, balancing data security with compliance. 
## Schedules 

Schedules enable recordings only at specified times, conserving storage for higher-priority periods (e.g., after-hours in sensitive areas). Set schedules in Settings > Recordings > Schedule to capture only essential footage. 
## Motion Detection Settings 

Customize motion detection to capture key events: 
- Seconds to start recording 
- Pre-event buffer (records moments before motion) 
- Post-event buffer (records moments after motion stops) 
Find these settings in Devices > [Select Camera] > Detection Record Settings to help limit non-essential footage, supporting compliance with data exposure regulations.

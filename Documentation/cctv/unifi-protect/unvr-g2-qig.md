# Network Video Recorder Gen 2 Installation Guide

How to install and set up Network Video Recorder Gen 2; Set up your UNVR-G2 for the first time.

Official interactive Quick Start Guide (HTML) for the UniFi **Network Video Recorder Gen 2** (UNVR-G2).

UX notes for Temco inspiration (from the official QIG page):

- First-run setup is a short illustrated guide, not a settings dump.
- Hardware orientation, drive install, and network/power connections are shown as numbered steps.
- The guide points operators into the UniFi Protect app after the appliance is on the LAN.
